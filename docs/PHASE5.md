# DSCNS Phase 5 — Intrinsic Parameter Self-Modification

**Phase**: P5 — Intrinsic Parameter Self-Modification (内生式参数自修改机制)
**Version**: v0.3.0 (prototype) · **Date**: 2026-08-18
**Status**: research prototype; single-seed experiments; no performance claims

> **重要声明（遵循设计报告）**：P5 不以"模型性能提升"作为证明自修改成立的
> 首要依据。本阶段需要证明的是：**模型内部状态能够产生依赖于自身当前状态的
> 参数变化，并且该参数变化能够改变模型未来状态，从而形成可重复、稳定、可测量
> 的参数—状态反馈闭环**。性能提升属于后续功能性验证。

---

## 1. 目标与边界

### 1.1 核心命题

$$
\boxed{\theta_t \rightarrow h_t \rightarrow \Delta\theta_t \rightarrow \theta_{t+1} \rightarrow h_{t+1} \rightarrow \Delta\theta_{t+1}}
$$

- $\theta_t$：时刻 $t$ 的模型参数（本原型中为每个认知网络的 LoRA 适配器权重）
- $h_t$：模型内部隐藏状态（GPT-2 最后一层隐藏状态，含 LoRA 贡献）
- $\Delta\theta_t = P_\phi(h_t, \text{stats}(\theta_t), s_t)$：可塑性机制产生的参数变化
- $s_t$：自身状态元信息（competence、uncertainty、学习进度等）

### 1.2 P5 是什么 / 不是什么

**是**：验证参数自修改闭环存在性的实验；探索内部状态驱动参数变化的机制；
为后续自主学习打基础的技术验证。

**不是**：完整的自主学习系统、性能最大化优化器、替代梯度下降的训练方法、
结构自适应系统（P6 目标）、自主决定"何时/为何修改"的系统（Level 4，超出范围）。

### 1.3 三个层次的边界（报告 §1.3 / §8）

| 层次 | 组件 | 属性 | 职责 |
|---|---|---|---|
| 1 | Plasticity Generation (`IntrinsicPlasticityModule`) | **模型内部机制** | 产生 Δθ |
| 2 | Parameter Transition (`apply_intrinsic_modification`) | **模型自身方法** | θ' = θ + α·Δθ |
| 3 | Trigger / Validation / Rollback / Logging | **实验控制器** | 实验调度与安全保护 |

触发器是外部固定频率（`plasticity_interval` 个梯度步触发一次），**不参与 Δθ
内容的生成**，不作为内生自修改机制的一部分。回滚是实验安全机制，不是自修改机制。

### 1.4 自修改层次

| Level | 描述 | 对应阶段 |
|---|---|---|
| 0 | 规则系统修改模型 | P3 |
| 1 | 外部神经网络决定修改 | P4 |
| 2 | 模型内部状态产生修改信号（经外部控制器） | P5 初版（已废弃） |
| **3** | **模型内部状态直接产生参数变化 `θ → h → Δθ → θ'`** | **P5-B 目标（本实现）** |
| 4 | 模型自主学习何时/如何/为何修改 | P5 后期 / P6 |

## 2. 实现

### 2.1 新模块

| 文件 | 内容 |
|---|---|
| `dscns/intrinsic_plasticity.py` | `IntrinsicPlasticityModule`（P_φ）：状态提取器、参数统计编码器、元信息编码器、融合层、低秩 ΔW = UVᵀ 生成器、可学习调制强度 |
| `dscns/plasticity_trainer.py` | `PlasticityTrainer`（P5-C）：成功案例记忆 + 奖励加权 MSE 离线训练 |
| `scripts/run_phase5_b.py` | P5-B 主实验（fixed / p5b 两臂，20 轮漂移流） |
| `scripts/run_phase5_c.py` | P5-C 实验（离线可塑性学习臂） |
| `scripts/run_negative_controls.py` | 负对照实验（random / constant / shuffled Δθ） |
| `scripts/validate_phase5.py` | Test 1-6 + 负对照验证编排 |
| `tests/test_phase5_core.py` / `tests/test_phase5_validation.py` | 验证套件 |
| `config/phase5.yaml` | P5 配置（对应报告 §13.1） |

### 2.2 数学形式

$$h_t = F(x_t, \theta_t)$$
$$\Delta\theta_t = P_\phi(h_t, \text{stats}(\theta_t), s_t)$$
$$\theta_{t+1} = U(\theta_t, \Delta\theta_t) = \theta_t + \alpha \cdot \Delta\theta_t$$
$$h_{t+1} = F(x_{t+1}, \theta_{t+1})$$

- 低秩生成：$\Delta W_A = U_A V_A^T$（$U_A \in \mathbb{R}^{768\times 8}$，
  $V_A \in \mathbb{R}^{16\times 8}$），与 LoRA 同构；Tanh 约束 + 可学习调制强度
- 参数感知：只使用 `[mean, std, min, max]`（4 维统计量），不用完整参数
- 跨 batch 平均："多经验共识"（报告 §6.3），同时保留逐样本 Δθ 用于分析
- 应用对象：适配器所有 hidden 维度的 `lora_A`（c_attn / attention c_proj）
  与 `lora_B`（c_proj / mlp c_proj）；c_attn 的 QKV 拼接输出投影 (3H, r) 与
  mlp c_proj 输入投影 (r, 3H) 在本原型中不施加（维度不匹配，见 LIMITATIONS）

### 2.3 CognitiveNetwork 集成（报告 §9.2 / §7）

- `self.plasticity`：模型成员（P_φ），不是外部观察者
- `apply_intrinsic_modification(delta, alpha)`：模型自身方法，θ' = θ + α·Δθ
- `snapshot_parameters()` / `restore_parameters()`：实验安全机制
- `generate_delta(texts, tokenizer)`：模型机制，h → Δθ
- `modulate_forward(...)`：P5-A 参数调制（瞬时施加后恢复，验证"内部状态影响
  自身计算"而不永久修改参数）
- `_get_meta_info(meta_dim)`：s_t 元信息向量（13 个特征 + padding 至 32）

### 2.4 与 P4 的本质区别（报告 §2.3 / §16.2）

| 维度 | P4 | P5-B |
|---|---|---|
| 决策主体 | 独立策略网络（外部观察者） | **模型内部可塑性机制**（成员） |
| 输入 | 统计量（外部观察） | 内部隐藏状态 h + stats(θ) + s |
| 输出 | 离散结构动作 | **连续参数变化 Δθ** |
| 修改对象 | 网络结构 | 参数值 |
| 闭环性质 | 开环（策略→模型） | **闭环（θ→h→Δθ→θ'）** |

## 3. 实验设置

- 底座：本地 GPT-2 (124M) 冻结 + 每网络 LoRA (r=16, α=32)
- 网络：5 个认知网络（N1..N5），每网络一个 `IntrinsicPlasticityModule`
- 数据：复用前序阶段缓存的 5 个公共数据集（wikitext/gsm8k/MATH-500/HumanEval/SciQ）
- 流：20 轮 = general(5) → code(5) → mixed_code(5) → science(5)，带放回采样
  （HumanEval 池小；P5 关注闭环而非数据策展）
- 计算预算：每轮每网络 4 个梯度步（batch=8，32 样本），与 P4 预算一致
- 外部触发：`plasticity_interval=4` 步 → 每轮每网络 1 次可塑性步骤
- 应用强度：`plasticity_alpha=0.01`（保守更新）；调制强度初始 0.05（可学习）
- 安全验证（实验控制器）：loss_after < loss_before + 0.5 nats（相对判据，
  偏离报告绝对 ppl<100 的理由：GPT-2 原始困惑度跨域波动大）
- 种子 42，单次运行

### 3.1 臂

| 臂 | delta 模式 | 说明 |
|---|---|---|
| fixed | — | 无可塑性（对照基线） |
| p5b | intrinsic | 内生 Δθ（主臂） |
| p5c | intrinsic + 离线学习 | P_φ 从成功案例学习（报告 §11） |
| random | random | 同等范数高斯 Δθ（Control A） |
| constant | constant | 每触发施加同一 Δθ（Control B） |
| shuffled | shuffled | Δθ 来自另一输入 batch（Control C） |

## 4. 核心验证（Test 1-6，报告 §10.1）

| Test | 命题 | 判据 |
|---|---|---|
| 1 Delta Existence | Δθ 存在且非数值噪声 | ‖ΔW_A‖, ‖ΔW_B‖ > 1e-6 |
| 2 State Dependency | 不同输入 → 不同 Δθ（含确定性 + 随机 h 消融） | 确定性差 < 1e-8；输入差、随机 h 差 > 1e-4 |
| 3 Parameter Transition | θ' ≠ θ | ‖θ' − θ‖ > 1e-6 |
| 4 Behavioral Change | F(x,θ') ≠ F(x,θ) | logits 差 > 1e-3 |
| 5 Closed-loop Loop | θ₀→Δθ₀→θ₁→Δθ₁→… 存在、非恒定、不发散 | 各步 Δθ > 1e-6；方差 > 1e-8；< 100 |
| 6 Stability | 连续 20 步不 NaN / 不爆炸 / 不归零 / 输出不崩溃 | NaN=0；范数 ∈ (1e-3, 1000)；熵 > 0.1 |

**P5-A（调制）验证**：`modulate_forward` 使 logits 变化 > 1e-3，且之后参数
与调制前完全一致（weights_restored=True）。

### 负对照（报告 §10.2）

- Control A：intrinsic Δθ 与同等范数随机 Δθ 行为效应可区分
- Control B：intrinsic Δθ 跨输入差异 > 1e-4（常数 Δθ 恒为 0）
- Control C：状态-Δθ 正确配对与打乱配对的效应可区分

## 5. 结果（单种子 42，原型尺度）

### 5.1 核心验证（Tests 1-6 + P5-A，全部通过）

| Test | 命题 | 观测值 | 判定 |
|---|---|---|---|
| 1 | Δθ 存在且非噪声 | ‖ΔW_A‖=0.667, ‖ΔW_B‖=0.694 | ✅ |
| 2 | 状态依赖（含消融） | 确定性差=0.0；跨输入差=0.231；随机 h 消融差=1.251 | ✅ |
| 3 | 参数转换 | ‖θ'−θ‖=32.66（α=1.0） | ✅ |
| 4 | 行为改变 | logits 差=0.212；预测变化率=0.91% | ✅ |
| 5 | 闭环存在、非恒定、不发散 | 5 步 Δθ 范数 1.364→1.400；方差 1.7e-4 | ✅ |
| 6 | 连续 20 步稳定 | 无 NaN；‖θ‖ 14.10→15.52；输出熵 3.873→3.864 | ✅ |
| P5-A | 瞬时调制 | logits 差=0.325；参数完全恢复 | ✅ |

### 5.2 负对照（可区分）

| 对照 | 观测值 | 判定 |
|---|---|---|
| A 随机 Δθ（同等范数） | intrinsic: pred-change 0.0% / logits 0.0202 vs random: 0.13% / 0.0207 | ✅ 效应不同 |
| B 常数 Δθ | intrinsic 跨输入差 0.168 ≫ 常数 Δθ 的 0 | ✅ |
| C 打乱状态-Δθ 配对 | 正确配对 logits 0.0198 vs 打乱 0.0192 | ✅ 可区分 |

### 5.3 最终对比实验（20 轮漂移流；性能为描述性指标）

| 指标 | fixed | p5b (intrinsic) | random | constant | shuffled |
|---|---|---|---|---|---|
| 最终平均性能（5 域） | **0.0413** | 0.0412 | 0.0405 | 0.0409 | 0.0407 |
| 平均遗忘 AF ↓ | **0.0090** | 0.0090 | 0.0097 | 0.0094 | 0.0095 |
| 前向迁移 FWT ↑ | 0.0002 | 0.0003 | 0.0002 | 0.0003 | 0.0002 |
| 持续学习分 CLS ↑ | **0.0323** | 0.0322 | 0.0308 | 0.0315 | 0.0312 |
| 可塑性触发次数 | — | 100 | 100 | 100 | 100 |
| 修改接受率 | — | 1.00 | 1.00 | 1.00 | 1.00 |
| Δθ 平均范数 | — | **1.285** | 1.310 | 1.325 | 1.288 |
| Δθ 范数方差（跨事件） | — | **4.8e-3** | 1.3e-2 | 3.3e-3\* | 1.8e-3 |
| 预测变化率（行为效应） | — | **0.014%** | 0.019% | 0.012% | 0.007% |
| logits 变化 | — | **0.0074** | 0.0078 | 0.0078 | 0.0081 |

\* constant 臂为"每网络恒定 Δθ"（不同网络缓存各自的恒定 Δθ），故跨事件
方差来自网络间差异，而非输入依赖。

**观察（诚实表述，单种子）**：p5b 与 fixed 的性能几乎相同（final_mean
0.0412 vs 0.0413，差异 ≈0.0001），符合 P5 不以性能为证明的设计；p5b 略好于
三个负对照臂（0.0405–0.0409）。在同等 Δθ 范数下，**内生 Δθ 的跨事件方差
最低（4.8e-3 vs 随机 1.3e-2）、行为扰动最小（预测变化 0.014% vs 随机
0.019%）**——与"状态对齐的结构化修改"一致。这些差异为单种子观测，
不构成统计显著结论。

### 5.4 P5-C（自适应可塑性学习，计算预算不对等，单独报告）

P5-C 按报告 §11 实现：每次接受的修改经 3 步短期适应后计算奖励
`reward = perf_after − perf_before`，奖励为正的案例进入成功记忆，随后
P_φ 以奖励加权 MSE 离线训练（重嵌入当前状态复现成功 Δθ）。

| 指标 | p5c |
|---|---|
| 触发 / 接受 | 100 / 100（接受率 1.00） |
| 成功案例（每网络） | 19/20 |
| 离线训练次数（每网络） | 11 |
| 平均奖励 | **+9.6e-4**（适应后性能普遍提升，奖励为正） |
| 未加权回放 MSE | 1.35e-5 → 1.90e-5（真实但极小） |
| 奖励加权损失 | ≈1e-9（P_φ 更新可忽略） |
| 最终平均性能 / AF / CLS | 0.0552 / 0.0007 / 0.0545 |

**诚实表述**：p5c 的最终性能显著高于其余各臂，但这是**混淆因素**——
每次触发附带 3 步适应学习（全流程每网络额外 60 步任务学习），额外的
任务学习直接提升了当前领域性能，**不能归因于可塑性学习**。可塑性模块
自身的离线信号（加权损失 ≈1e-9）在本原型尺度下可忽略：P_φ 对
(h, stats(θ), s) 的生成是确定性的，成功 Δθ 几乎可被精确复现，奖励尺度
（≈7e-5）进一步压低了加权信号。因此 P5-C 在本运行中**未观察到可测量的
可塑性改进**——这是原型尺度下离线模仿设计的真实（负向）结果，已在
`docs/LIMITATIONS.md` §8 记录。

## 6. 结论与边界

### 6.1 结论（保持诚实）

1. **闭环成立（Test 1-6 全过）**：模型内部状态确实产生依赖自身状态的非零、
   连续参数变化，参数变化改变模型行为，且闭环可重复、稳定、不发散。
2. **状态依赖**：Δθ 对不同输入有显著差异（跨输入差异 ≫ 阈值），且与随机 /
   常数 Δθ 可区分。
3. **性能为描述性指标**：P5 不以性能提升为证明；性能表仅作记录，单种子下
   的微小差异（≈0.00x）不构成统计显著结论。

### 6.2 明确不声称

- 不声称性能超过 P4 / 固定拓扑
- 不声称模型"自主决定何时修改自己"（外部固定触发器）
- 不声称端到端可微自修改（Δθ 生成在 no_grad 下；P5-C 为离线学习）
- 不声称解决持续学习 / 灾难性遗忘 / 通用自主性

### 6.3 局限（详见 docs/LIMITATIONS.md §8）

- 单种子、原型尺度（GPT-2 small、单层 LoRA、单种子）
- 参数感知仅用 4 维统计量（报告承认的低维近似）
- Δθ 仅施加于 hidden 维度的 LoRA 投影（QKV/MLP 输入投影跳过）
- 外部固定触发；回滚/验证是实验控制器职责
- P5-C 在极小记忆与训练预算下进行，效果有限
